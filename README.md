# Learnify – Responsive Education Landing Page

## Project Overview
Learnify is a fictional educational platform designed to help students learn new skills and build their careers through online courses.

## Target Audience
- College students
- Beginners learning programming
- Students interested in UI/UX design
- Individuals who want to develop professional skills

## Design Features
- Responsive desktop and mobile landing page
- Header with logo, navigation links and call-to-action button
- Hero section with heading, description and illustration
- Three feature cards:
  - Expert Courses
  - Learn Anytime
  - Certificates
- Course section
- Call-to-action section
- Footer with navigation and social links

## Reusable Components
1. Primary Button
2. Feature Card
3. Course Card

## Design Choices
- **Primary Color:** Purple (#6C4CE4)
- **Background:** White and light lavender
- **Typography:** Inter
- **Style:** Clean, modern and student-friendly

Auto Layout is used to organize the layout, buttons, cards and content sections.
